# Спальный район — основной экран

> Топология района и направления переходов задаются только [`../../graphs/map.drawio`](../../graphs/map.drawio).

## Назначение
Основная игровая точка навигации внутри гиперкластера «Спальный район».

При возвращении в район транспортом игрок попадает сюда, а не в системную точку автобусной остановки.

## Визуальный паспорт
Частично известен общий характер района: обычная жилая застройка, новый аккуратный дом Насти и Маши, нормальный благоустроенный двор. Полная композиция экрана — `TBD`.
