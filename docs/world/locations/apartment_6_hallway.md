# Квартира №6 Ники — прихожая

> Существующие переходы из прихожей и их направление задаются только [`../../graphs/map.drawio`](../../graphs/map.drawio).

## Назначение
Входная зона квартиры Ники.

## Первое посещение 29 августа
Ника не проводит экскурсию: игроку показывается только прихожая, где происходит короткий бытовой разговор. Остальные помещения квартиры существуют на карте, но не должны становиться доступными только потому, что они уже имеют карточки.

## Условия доступа
29 августа прихожая доступна с 19:00 до 22:00, пока social state Ники — `neutral`. После первого разговора устанавливается одноразовый runtime-флаг завершения визита. Остальные помещения раскрываются отдельными флагами/условиями.
