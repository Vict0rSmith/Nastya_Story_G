# Объекты — карта раздела

Здесь хранятся карточки устойчивых интерактивных объектов пространства: внешний вид, состояния, осмотр, доступные действия и прямые связи. Для новых карточек использовать [`../../templates/OBJECT_TEMPLATE.md`](../../templates/OBJECT_TEMPLATE.md). Переносимые или принадлежащие персонажу физические вещи описываются как [items](../items/README.md); товар не получает вторую object-карточку только из-за появления в комнате, магазине или событии.

Отдельных object-карточек пока нет. Не создавать объект только ради упоминания предмета в сцене или локации: отдельная карточка нужна, когда предмет имеет устойчивое состояние, интерактивность или используется несколькими сущностями/сценами.

Карта мира: [`../README.md`](../README.md).
