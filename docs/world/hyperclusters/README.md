# Гиперкластеры — карта раздела

Крупные зоны мира. Карточка гиперкластера задает смысл зоны, правила открытия/работы, связанные системы и общий визуальный характер.

**Топология гиперкластеров, их вложенность и маршруты между узлами не дублируются здесь. Единственный канонический источник карты — [`../../graphs/map.drawio`](../../graphs/map.drawio).**

- [`residential_district.md`](residential_district.md) — стартовый спальный район.
- [`hc_university.md`](hc_university.md) — район медицинского института; стабильный системный ID гиперкластера сохраняется `hc_university`.

Транспортные правила: [`../../systems/TRANSPORT_SPEC.md`](../../systems/TRANSPORT_SPEC.md). Условия доступности конкретных помещений хранятся в их карточках `../locations/`, а не в карте.
