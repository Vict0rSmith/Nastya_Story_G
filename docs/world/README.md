# База мира — карта раздела

Канонические сущности игрового мира. Верхнеуровневая карта проекта: [`../MASTER_SPEC.md`](../MASTER_SPEC.md). Правила зависимостей и change-impact: [`../REPOSITORY_MAP.md`](../REPOSITORY_MAP.md).

- [`characters/`](characters/) — полный индивидуальный канон центральных персонажей.
- [`npcs/`](npcs/) — системные карточки NPC; для персонажей без отдельного canon-файла здесь же хранится их индивидуальный профиль.
- [`hyperclusters/`](hyperclusters/) — крупные зоны мира.
- [`locations/`](locations/) — конкретные пространства и помещения.
- [`objects/`](objects/) — значимые и интерактивные объекты.
- [`items/README.md`](items/README.md) — переносимые и принадлежащие персонажу вещи, включая одежду и ассортимент секс-шопа.
- [`actions/`](actions/) — карточки игровых действий и семантика действий отдельных дней.
- [`effects/`](effects/) — состояния и эффекты.
- [`quests/`](quests/) — игровые задания, цели и условия.

Стабильные машинные ID связывают сущности между собой. Карточка хранит только факты своей ответственности; связанные сведения не копируются, а связываются ссылками.
