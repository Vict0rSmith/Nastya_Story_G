# TASK-000 — Импорт существующих проектных ТЗ

## Цель
Перенести в GitHub-базу четыре существующих Markdown-ТЗ из локального проекта Nastya Story без пересказа, сокращения и смыслового редактирования.

## Что найти в локальном проекте

1. `CHARACTERISTICS_SPEC.md`
2. `RELATIONSHIPS_INVENTORY_WARDROBE_SPEC.md`
3. `TIME_ACTIONS_QUESTS_EVENTS_SPEC.md`
4. `UI_VISUAL_SYSTEM_SPEC.md`

Использовать именно актуальные локальные версии этих файлов.

## Куда скопировать

```text
docs/systems/CHARACTERISTICS_SPEC.md
docs/systems/RELATIONSHIPS_INVENTORY_WARDROBE_SPEC.md
docs/systems/TIME_ACTIONS_QUESTS_EVENTS_SPEC.md
docs/systems/UI_VISUAL_SYSTEM_SPEC.md
```

## Правила

- Копировать содержимое 1:1.
- Не переписывать стиль.
- Не сокращать.
- Не «улучшать» архитектуру.
- Не подмешивать новые спецификации питания, транспорта, университета и HUD-эффектов внутрь старых файлов.
- Новые дополнения уже существуют отдельными каноническими файлами в `docs/systems/`.
- Если локально найдено несколько одноименных версий, не выбирать наугад: показать владельцу пути/даты и запросить выбор.

## После копирования

1. Создать implementation report в `docs/tasks/review/`.
2. Перечислить фактические исходные пути четырех файлов.
3. Указать, были ли найдены дубликаты/варианты.
4. Указать commit SHA.
5. Перевести исходный TASK в `review` согласно правилам репозитория.

## Не делать

- не изменять игровой код;
- не рефакторить документацию;
- не разрешать противоречия между старыми и новыми спеками самостоятельно.

После импорта противоречия отдельно проверит ChatGPT вместе с владельцем проекта.
