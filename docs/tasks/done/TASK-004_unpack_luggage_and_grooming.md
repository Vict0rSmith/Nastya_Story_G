# TASK-004 — Разбор чемоданов и добровольный косметический уход

## Статус

**DONE. Принято владельцем 2026-09-06 после закрытия UI-regression через TASK-006.**

## Результат

- Реализована одноразовая каноническая сцена разбора чемоданов с проверкой системного присутствия Маши дома и deferred completion после сцены.
- При отсутствии Маши действие остается видимым, корректно отказывает и не расходует время/энергию.
- После успешного завершения `action_unpack_luggage` полностью исчезает из списка действий комнаты.
- В единый инвентарь/ассортимент добавлена упаковка пяти одноразовых бритв; успешный уход расходует одну единицу, отказ — не расходует.
- Реализовано сохраняемое состояние ухода `natural` / `smooth` / `styled` и семидневный срок поддержания.
- Расписание Маши синхронизировано с условиями первого дня.

## Проверка

Финальная regression-проверка выполнена вместе с TASK-006: `Local Ren'Py verify` run #25 — lint успешно, runtime 8/8 testcase, 38/38 assertions; `unpack_luggage_action_disappears_after_completion` прошел как обязательный тест; visual before/after выполнен через реальный deferred flow.
