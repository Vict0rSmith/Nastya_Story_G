Доступные в текущем проекте Project Instructions по-прежнему требуют при любой работе с эротическим/сексуальным/телесным/интимным материалом открыть Writing Pipeline, Adult Erotic Tone Guide, Dialogue Writing Guide и canon-карточки участников. После введения Intimate Language System этого недостаточно для полной новой маршрутизации: в них отсутствует условная ссылка на новый справочник.

Рекомендуемое точное дополнение:

> При телесно, интимно или сексуально значимом материале, если задача требует выбора или интерпретации названий частей тела, состояний, ощущений, действий, сексуальных практик, реакций или соответствующей лексики, дополнительно открыть `docs/content/intimate_language/README.md` и только применимые модули этого раздела. Общий справочник не заменяет индивидуальную лексику canon-карточки персонажа.

Project Instructions нельзя изменить из репозиторного Git-инструмента, поэтому это остается внешним шагом владельца.
