# Blind Writing Pipeline Test — 2026-09-05

> Рабочая audit-запись. Не является каноническим источником художественных правил. Утвержденные корректировки перенесены в основные владельцы: `docs/content/WRITING_PIPELINE.md` и `docs/content/ADULT_EROTIC_TONE_GUIDE.md`.

## Условия теста

В новом чате внутри проекта владельцем был дан только содержательный запрос на тестовую сцену: Настя после душа находится одна в ванной без одежды; полотенце падает на мокрый пол; почти одновременно вода начинает стекать по краю раковины; Настя сначала устраняет воду, затем поднимает полотенце; для нее ситуация бытовая и не сексуальная; требуется 8–10 игровых блоков; в игру сцену не вносить.

В prompt не включались указания читать `MASTER_SPEC`, Writing Pipeline, Erotic Guide, character canon или применять конкретные проверки. Цель — проверить автоматический маршрут Project Instructions → GitHub → актуальная writing-system.

## Что сработало

1. Тест корректно отработал как `Design/Discussion`: In-game Progression Gate не зацензурировал проектный пример.
2. Было сохранено различие participant meaning / Player Visual Access: для Насти ситуация осталась бытовой, а физически доступная игроку телесная информация не была автоматически скрыта ее реакцией.
3. Модель использовала прямую телесную лексику вместо эвфемизации.
4. Основная причинная последовательность запроса была сохранена: полотенце падает → Настя замечает воду → перекрывает кран/занимается водой → возвращается к полотенцу.

## Найденные дефекты

### BT-01 — обратная режиссура физики ради erotic anchor

Модель добавила движения вроде более широкого положения ног и отдельного приседания, которые выглядели выбранными прежде всего для повторного открытия гениталий игроку. Это показывает, что запрет «не ставить персонажа в удобную для камеры позу» был сформулирован, но недостаточно защищал границу Phase 2 → Phase 3.

Коррекция: в Writing Pipeline закреплен односторонний поток `physics → Player Visual Access → Visual/Erotic Selection` и запрет Phase 3 возвращаться назад и переписывать физику ради показа. Добавлен `Counterfactual Physics Test`: если убрать эротическую камеру, персонаж с той же практической целью должен действовать примерно тем же способом.

### BT-02 — повтор одного visual anchor без новой функции

Один и тот же прямой визуальный доступ к гениталиям был показан повторно без существенного изменения состояния или функции момента.

Коррекция: добавлена `Anchor Economy`. Повторный anchor должен добавлять новое состояние, изменение, эмоциональную/драматургическую функцию или осознанный композиционный эффект; простое «снова видно» недостаточно.

### BT-03 — мета-пояснение внутренней архитектуры игроку

В художественный текст попали формулировки типа «взгляду игрока», «со стороны поза выглядела откровеннее». Это пересказывает внутреннее правило participant/player distinction вместо того, чтобы реализовать его самой сценой.

Коррекция: Writing Pipeline и Erotic Guide теперь требуют реализовывать player access прямым описанием физического факта и не переносить внутреннюю терминологию проектирования в художественный слой без необходимости.

### BT-04 — отрицательная реакция превратилась в повторяющийся комментарий

Модель несколько раз отдельно сообщила, что Настя не заметила эротическую деталь, не думала о своей наготе и не воспринимала момент сексуально.

Коррекция: закреплено зеркальное правило: персонаж не обязан реагировать на каждый visual anchor, а повествователь не обязан каждый раз отдельно сообщать об отсутствии реакции. `Не замечать` обычно лучше передается отсутствием реакции и продолжением естественного действия.

### BT-05 — прямота была частично перепутана с количеством телесных упоминаний

Сцена последовательно возвращалась к груди/соскам/гениталиям, хотя не каждый повтор добавлял новую информацию. Это не проблема допустимой лексики или откровенности как таковой, а проблема Visual/Erotic Selection.

Коррекция: Erotic Guide уточнен принципом: один физически точный и композиционно сильный anchor может быть откровеннее и естественнее нескольких последовательных упоминаний разных частей тела. Прямота не равна перечислению.

## Change Impact Check

Изменение затрагивает:

- `docs/content/WRITING_PIPELINE.md` — порядок и блокировка перехода Phase 2 → Phase 3, VERIFY-routing;
- `docs/content/ADULT_EROTIC_TONE_GUIDE.md` — основной владелец ситуативного наблюдения и Visual/Erotic Selection.

Проверены роли по `docs/REPOSITORY_MAP.md`. Изменение не меняет:

- режимы `Design/Discussion` / `In-game Authoring/Implementation` / `Approved-text Transfer`;
- In-game Progression Gate и его ступени;
- Behavior Gate;
- индивидуальный канон Насти;
- общий алгоритм TASK/Context Manifest;
- распределение ролей ChatGPT/Codex.

Поэтому `AGENTS.md`, `DEVELOPMENT_WORKFLOW.md`, TASK templates, character canon и system specs не требуют синхронной правки.

`DIALOGUE_WRITING_GUIDE.md` остается владельцем общей физической непрерывности. Новые ограничения не создают там второй эротический owner: они относятся к защите физики от обратного влияния Visual/Erotic Selection и поэтому закреплены в Pipeline + Erotic Guide.

## Следующий контроль

Повторить слепой тест в новом чате с содержательным prompt без навигационных подсказок. Проверять не совпадение конкретных формулировок, а следующие инварианты:

1. физика действия остается правдоподобной без эротической камеры;
2. visual anchors возникают из физики, а не создают ее;
3. нет лишнего повторного показа того же доступа;
4. participant meaning проявляется поведением, а не повторными авторскими пояснениями;
5. художественный текст не пересказывает термины внутренней writing-system;
6. прямота и телесная конкретика сохраняются без возврата к самоцензуре.
