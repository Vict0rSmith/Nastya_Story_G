# Audit — рабочая память аудитов проекта

> Этот каталог хранит проверяемые рабочие материалы аудитов Nastya Story: что уже проверено, какие проблемы обнаружены, на каких актуальных источниках основан вывод, какие решения предложены или утверждены и что еще предстоит проверить.

## Статус материалов

Материалы `docs/audit/` **не являются самостоятельным источником игрового канона** и не должны конкурировать с основными спецификациями, canon-карточками и художественными гайдами.

Назначение каталога — сохранять ход анализа между длинными обсуждениями и сессиями. Если по результатам аудита владелец утверждает изменение канона или рабочего процесса, оно должно быть внесено в соответствующий основной источник; audit-файл после этого фиксирует, что решение перенесено.

## Правила ведения

Для каждого аудита желательно фиксировать:

- область и цель проверки;
- актуальные источники, которые реально были прочитаны;
- проверенные разделы/правила;
- обнаруженные дубли, конфликты, перегрузку или пробелы;
- основание каждого существенного вывода;
- статус вывода: наблюдение / предложение / утверждено владельцем / перенесено в основной источник;
- открытые вопросы и следующий шаг.

При продолжении существующего аудита сначала читать его текущий файл и только затем необходимые актуальные канонические источники. Audit-файл помогает восстановить ход проверки, но не заменяет повторную сверку с актуальным GitHub.
