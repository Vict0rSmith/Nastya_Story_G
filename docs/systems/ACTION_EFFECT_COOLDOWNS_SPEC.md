# Группы восстановительных эффектов и кулдауны действий

Статус: утверждено.

## 1. Принцип

Разделять само действие и полезный восстановительный эффект. Повторное бытовое действие обычно не запрещается только потому, что бонус уже получен.

Длительности действий находятся в централизованном каталоге действий и не прописываются вручную в каждой сцене.

## 2. Группа `hygiene_restore`

Участники:
- принять душ;
- принять ванну.

Если группа готова:
- действие выполняется;
- время продвигается;
- восстанавливается базово `+1` энергия;
- запускается общий кулдаун;
- используется ярко положительная реакция Насти («как заново родилась» и т. п.).

Если группа на кулдауне:
- душ/ванна все равно доступны;
- время продвигается;
- энергия повторно не восстанавливается;
- используется нейтральный текст: Настя и так чистая, но может освежиться.

Душ и ванна делят один кулдаун. Ориентир — несколько часов (примерно 6–8), точное число задается балансом.

## 3. Группа `rest_restore`

Участники:
- поваляться/отдохнуть;
- посмотреть телевизор.

Первое действие после готовности группы:
- продвигает время;
- восстанавливает базово `+1` энергию;
- запускает общий кулдаун.

Повторное действие во время кулдауна:
- разрешено;
- только продвигает время;
- не восстанавливает энергию.

Телевизор и лежание используют один эффект, чтобы игрок не мог чередованием бесконечно восстанавливать энергию.

## 4. Еда отличается от этих групп

Для полноценной еды используется не «кулдаун бонуса», а состояние сытости. Пока Настя сыта, повторный прием пищи блокируется полностью без расхода еды и времени. Подробности — `NUTRITION_SPEC.md`.

## 5. Универсальность

Механизм должен быть общим: действие может ссылаться на `effect_group`, а группа хранит `ready_at`/эквивалентное состояние. Не создавать отдельные одноразовые переменные для каждого бытового действия.

## 6. Нарратив

Системный результат и текст реакции разделены. При готовом эффекте и при кулдауне должны поддерживаться разные текстовые варианты. Позже для повторяемых действий желательно иметь несколько нарративных вариантов, чтобы текст не повторялся дословно.
