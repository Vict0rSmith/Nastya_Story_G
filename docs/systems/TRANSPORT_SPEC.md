# Транспорт и перемещение между гиперкластерами

Статус: утверждена базовая версия.

## 1. Гиперкластеры

Мир делится на крупные зоны — гиперкластеры: спальный район, район медицинского института, центр города и будущие зоны. Внутри гиперкластера игрок перемещается по обычным локациям; между гиперкластерами используется транспорт.

Топология крупных зон и существующие между ними маршруты задаются только [`../graphs/map.drawio`](../graphs/map.drawio).

## 2. Транспортный маршрутизатор

В первой версии единственный междукластерный транспорт — автобус.

На карте автобусная остановка показана **ромбом**. Это не самостоятельная локация пребывания и не значение `location_id`, а системная точка маршрутизации: при выборе соответствующего интерактивного элемента текущего гиперкластера открывается транспортный интерфейс со списком известных и доступных направлений.

Для каждого направления показывается временная стоимость поездки до подтверждения выбора.

Пример:
- район медицинского института — N минут;
- центр города — N минут.

Тот факт, что транспортный маршрут существует на `map.drawio`, не означает, что направление уже открыто игроку. Доступность конкретного направления определяется данными/флагами транспортной системы.

## 3. Маршрут

Маршруты должны храниться как данные, а не быть зашиты в сценах.

Рекомендуемая сущность:
```python
{
  "from": "hc_residential_district",
  "to": "hc_university",
  "mode": "bus",
  "duration_minutes": DATA_VALUE
}
```

После подтверждения:
- продвигается единое игровое время;
- игрок переносится во входную точку целевого гиперкластера, определенную реализацией этого гиперкластера;
- транспортный ромб сам не становится текущей локацией игрока;
- отправляются события перемещения/входа в локацию;
- время поездки учитывается дедлайнами.

При прибытии в спальный район игрок оказывается на основном экране гиперкластера, а не на отдельном экране остановки.

## 4. Будущее расширение

Архитектура сразу должна поддерживать `mode`, хотя в v1 реализуется только `bus`.

Будущие варианты:
- `walk` — медленнее, возможно с энергетической стоимостью;
- `taxi` — быстрее, но за деньги;
- другие виды транспорта.

Нельзя архитектурно приравнивать «переход между гиперкластерами» к автобусу навсегда.

## 5. Сюжетный дедлайн университета

Последний безопасный момент отправления 29 августа рассчитывается из:
`18:00 - travel_time - safety_margin`.

В сценах не хардкодить конкретное время последнего автобуса/отправления, если оно может быть вычислено из маршрута и дедлайна.


## 6. Время перемещения — решение владельца от 7 сентября 2026

- Автобусная поездка занимает **20 минут**.
- Переход между зданиями и по наружным пространствам занимает **5 минут**.
- Переход внутри здания, между комнатами или этажами, занимает **1 минуту**; это заменяет прежние 5 минут в runtime квартиры.

При компиляции карты принадлежность одному зданию определяется внешним контейнером составной локации. Двор дома, детская площадка и школьная спортивная площадка считаются наружными пространствами. Первый этаж учебного корпуса и приемная комиссия относятся к одному зданию, хотя на карте у них нет отдельного контейнера корпуса.

Длительности не меняют направление или наличие маршрутов. Неопределенная доступность помещений остается `TBD`; создание данных не открывает их автоматически.
