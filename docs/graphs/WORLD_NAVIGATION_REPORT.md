# Синхронизация локаций и переходов — 7 сентября 2026

Статус: реализация навигации выполнена по прямому поручению владельца, ожидает его приемки. Уровень проверки: `FULL_LOCAL`.

## Результат

- Все 92 узла `map.drawio` представлены в машинных данных: 77 мест пребывания, 14 контейнеров и один маршрутизатор.
- В игровом реестре добавлены 69 ранее отсутствовавших мест пребывания. Технический `loc_masha_school` сохранен для существующего расписания Маши и недоступен как цель перемещения игрока.
- Все 157 уникальных направленных пеших переходов скомпилированы из карты. Повторные линии не создают повторные кнопки, draw.io-defaults учтены. Карта и ее геометрия не изменялись.
- Четыре транспортных направления получены через автобусный маршрутизатор. Линии без наконечников используются как системные связи, а не как пешие переходы. Маршрутизатор не становится текущей локацией.
- Созданы 28 минимальных карточек пространств центрального района и карточка гиперкластера. Неутвержденные данные оставлены `TBD`; карточки включены в тематические MOC.
- По решению владельца автобус занимает 20 минут, наружные переходы — 5 минут, внутренние — 1 минуту. Решение зафиксировано в `TRANSPORT_SPEC.md`.
- HUD показывает существующие направления, недоступные помещения — отключенными кнопками с причиной. Длинные названия переносятся в пределах плитки; переходы и действия размещаются в отдельных половинах экрана в один ряд **без горизонтальной прокрутки**. Одноименные бутики различаются номером из стабильного ID; у этажей указаны номера подъездов, у прихожих — номера квартир. На доступных плитках есть подсказка с родительским пространством.
- Реализована проверка доступа при перемещении: открытые пространства, закрытые двери, ключ подвала, окно приемной комиссии с учетом времени прибытия. При отказе время и локация не меняются.

## Ограничения и найденные особенности

- Центральный район, частные комнаты и другие места с `conditional: TBD` / `tbd` созданы в данных, но автоматически не открыты. Новые карточки не утверждают доступ или содержимое вместо владельца.
- Карта не содержит обратной стрелки от центральной улицы к автобусному маршрутизатору. Поэтому обратный автобус из центра не придуман. Сейчас центр недоступен по `TBD`; перед его открытием следует утвердить обратный маршрут либо подтвердить односторонность.
- В карте есть повторные линии для кухни/ванной квартиры №5 и ресэпшена/парикмахерской. Их геометрия сохранена; runtime объединяет совпадающие направления.
- Художественные фоны, отдельные иконки новых мест и литературные описания не утверждены. Runtime использует существующий фон-заглушку и штатную fallback-плитку. Это проверка навигации, а не завершенное художественное оформление мира.
- Квестовые действия подачи документов, посещения Ники, торговли и защита сюжетного дедлайна не добавлялись: они выходят за поручение о локациях и переходах. Часы при поездках продвигаются общей системой.
- Формат сохранений не менялся, старые ID сохранены. Карта остается единственным владельцем топологии; сгенерированные данные нельзя редактировать вручную.
