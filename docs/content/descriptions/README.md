# Описания — карта раздела

Здесь могут храниться переиспользуемые авторские описания локаций, предметов, действий, перемещений, варианты повторных текстов и реакции/отказы. Отдельных файлов пока нет.

Факты сущности остаются в ее канонической карточке; этот раздел хранит только текстовое представление и связывается с сущностями по ID/ссылкам. Не создавать отдельную библиотеку ради единственного текста, который естественно принадлежит одной сцене или карточке.
