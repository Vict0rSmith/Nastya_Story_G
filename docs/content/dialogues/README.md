# Диалоги — карта раздела

Здесь хранятся самостоятельные диалоговые библиотеки и повторно используемые разговорные блоки. Отдельных файлов пока нет.

Диалог не является вторым источником характера персонажа или фактов мира: индивидуальная речь берется из [`../../world/characters/`](../../world/characters/) либо из NPC-карточки персонажа без отдельного canon-файла; общие правила текста — из [`../DIALOGUE_WRITING_GUIDE.md`](../DIALOGUE_WRITING_GUIDE.md).

Новый отдельный dialogue-файл создавать, когда разговорный блок действительно переиспользуется или существует независимо от одной конкретной сцены.
