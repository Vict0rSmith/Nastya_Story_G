# Интимная и телесная лексика — карта раздела

Этот раздел — канонический справочный слой для телесной, интимной и сексуальной семантики Nastya Story. Он помогает сначала точно установить физический факт, состояние, ощущение, действие, практику и реакцию, а затем подобрать естественную формулировку под авторский слой и голос конкретного персонажа.

## Что здесь хранится

- [INTIMATE_LANGUAGE_SYSTEM.md](INTIMATE_LANGUAGE_SYSTEM.md) — архитектура системы, стабильные ID, регистры, точность, интенсивность, intent/consent/risk и порядок выбора формулировки.
- [BODY_LEXICON.md](BODY_LEXICON.md) — современные названия частей тела и интимных зон с регистрами и семантической точностью.
- [STATES_SENSATIONS_REACTIONS.md](STATES_SENSATIONS_REACTIONS.md) — состояния тела, изменения, ощущения, непроизвольные реакции и результаты.
- [BODY_ACTIONS.md](BODY_ACTIONS.md) — универсальные физические действия с телом и их языковые реализации.
- [SEXUAL_PRACTICES.md](SEXUAL_PRACTICES.md) — сексуальные и эротические практики как контекст действий: мастурбация, стимуляция, bondage/BDSM, pain play, exhibition, voyeurism, fetish, toys и другие.
- [CHARACTER_LANGUAGE_PROFILE.md](CHARACTER_LANGUAGE_PROFILE.md) — правила привязки общего словаря к индивидуальному голосу персонажа без дублирования его canon-карточки.

## Когда открывать

Раздел не является обязательным контекстом для каждой сцены.

При телесно, интимно или сексуально значимом материале сначала применяется [WRITING_BRIEF.md](../WRITING_BRIEF.md) (границы, ступень, режим). Затем открыть этот README и только те модули, которые реально нужны:

- нужно назвать часть тела → BODY_LEXICON;
- важны влажность, напряжение, боль, удовольствие, дрожь, дыхание и иные состояния/ощущения/реакции → STATES_SENSATIONS_REACTIONS;
- свериться с реальной физиологией (влага, оргазм, сквирт, сперма, растяжение, следы) → справочник STATES_SENSATIONS_REACTIONS §14, необязательно, гипербола допустима;
- важно конкретное прикосновение, давление, щипок, проникновение, связывание, наблюдение или демонстрация → BODY_ACTIONS;
- действие является частью мастурбации, BDSM, voyeurism, exhibition, fetish, toy play и т. п. → SEXUAL_PRACTICES;
- нужно выбрать, как именно это скажет или подумает персонаж → его canon-карточка + CHARACTER_LANGUAGE_PROFILE;
- нужно назвать часть тела в авторской речи → CHARACTER_LANGUAGE_PROFILE §5.

Не загружать весь раздел «на всякий случай».

## Владение фактами

- Этот раздел владеет общей семантикой телесных терминов, действий, состояний и практик.
- [ADULT_EROTIC_TONE_GUIDE.md](../ADULT_EROTIC_TONE_GUIDE.md) владеет жанровой эротической оптикой, progression и scripted override.
- [DIALOGUE_WRITING_GUIDE.md](../DIALOGUE_WRITING_GUIDE.md) владеет общими правилами речи, описаний, Humanization и физической непрерывности.
- Canon-карточка персонажа владеет его устойчивой индивидуальной лексикой, частотой, социальным фильтром, предпочтениями и запретами.
- Системные спецификации владеют игровыми механиками. Наличие слова, действия или практики в этом справочнике не открывает ее персонажу, не создает квест, не меняет характеристику и не делает практику канонической для конкретного персонажа.
- Сцена/квест владеет фактом конкретного события.

## Базовый принцип

Сначала определить, что объективно произошло, затем — как это воспринимается и только после этого — как это назвать.

BODY → STATE / CHANGE → SENSATION → ACTION → CONTEXT → PRACTICE → RESPONSE → OUTCOME → LANGUAGE → CHARACTER VOICE

Нельзя менять физический факт ради более удобного или более эротичного слова.

## Разговорный default

Точная внутренняя семантика не означает терминологическую речь персонажей. Если индивидуальная телесная/интимная лексика персонажа не определена (`TBD`), по умолчанию используется естественный современный разговорный русский из `DIALOGUE_WRITING_GUIDE.md`, а не медицинский/анатомический регистр.

Анатомические формы вроде `вульва`, `влагалище`, `наружные половые органы`, `вагинальный канал` остаются доступными для точного, медицинского, научного, формального или специально обусловленного контекста, но не выбираются автоматически только потому, что точнее совпадают с BODY ID. В бытовом, дружеском, потребительском и эротическом разговоре допустимы более простые слова и контекстные формулировки; устойчивое любимое слово конкретного персонажа при этом не додумывается без его canon-карточки.

## Граница словаря

Словарь ориентирован на современный употребимый русский язык Nastya Story. Редкие, архаичные, региональные и словарно-экзотические формы сознательно не включаются, если нет отдельной причины использовать их в голосе конкретного персонажа.
