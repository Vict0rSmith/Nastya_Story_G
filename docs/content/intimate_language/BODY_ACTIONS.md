# Body Actions — универсальные действия с телом

## 1. Принцип

ACTION описывает физически наблюдаемое действие, а не его сексуальный смысл. Смысл задают INTENT, CONSENT, PRACTICE и контекст сцены.

## 2. Базовые действия прикосновения

| ID | Нейтральные формы | Разговорные/вариативные |
|---|---|---|
| action.touch | коснуться, тронуть | потрогать |
| action.stroke | погладить, гладить, провести ладонью/пальцами | ласково провести рукой |
| action.rub | потереть, растирать | тереть |
| action.press | надавить, прижать | прижать сильнее |
| action.squeeze | сжать, стискивать | мять, помять, пожамкать (JOKE) |
| action.pinch | ущипнуть, зажать пальцами | щипнуть, пощипывать |
| action.pull | потянуть | тянуть |
| action.twist | повернуть/покрутить пальцами | крутить |
| action.scratch | провести ногтями, поцарапать | царапать |
| action.bite | укусить | прикусить |
| action.kiss | поцеловать | целовать |
| action.lick | лизнуть, провести языком | лизать |
| action.suck | втянуть губами, сосать | посасывать |

У каждого действия фиксируется BODY_TARGET и INTENSITY.

## 3. Грудь и соски

Типовые сочетания:
- touch + breast: коснуться груди / тронуть сиську / потрогать грудь;
- stroke + breast: гладить грудь / провести ладонью по груди;
- squeeze + breast: сжать грудь / мять грудь / помять сиську;
- touch + nipple: коснуться соска / провести пальцем;
- rub + nipple: потереть сосок;
- pinch + nipple: ущипнуть сосок / щипнуть сосочек / пощипывать соски;
- squeeze + nipple: сжать сосок пальцами / зажать сосок;
- pull + nipple: потянуть за сосок;
- twist + nipple: покрутить сосок / катать сосок между пальцами;
- lick/suck/kiss + nipple: поцеловать, лизнуть, сосать сосок.

Фраза выбирается по LANGUAGE и character profile; ACTION остается тем же.

## 4. Ягодицы

- stroke + buttock: погладить ягодицу / гладить попу;
- squeeze + buttock: сжать ягодицу / сжать попу / мять попу;
- grab + buttock: схватить за попу / обхватить ягодицу;
- slap + buttock: шлепнуть по попе / хлопнуть по ягодице;
- pinch + buttock: ущипнуть за попу;
- spread + buttocks: раздвинуть ягодицы / раздвинуть попу.

## 5. Вульва и половые губы

- touch + vulva: коснуться вульвы / потрогать письку / трогать киску;
- stroke + vulva: гладить / ласкать / провести пальцами;
- rub + vulva: тереть / потирать;
- press + vulva: прижать ладонь / надавить;
- spread + labia: раздвинуть половые губы / развести губы / раздвинуть губки;
- stroke + labia: провести пальцами по губам / между губами;
- squeeze + labia: мягко сжать губы пальцами — только если это физически установлено сценой.

«Раздвинуть киску» возможно как разговорная формулировка, но семантически менее точно, чем spread + labia.

## 6. Клитор

- touch: коснуться клитора / тронуть клиторчик;
- stroke: гладить клитор / провести пальцем;
- rub: тереть / потирать клитор;
- circle: водить пальцем вокруг клитора;
- press: прижать палец / надавить;
- pause: прекратить или ослабить стимуляцию.

«Трогать кнопочку» возможно только при подходящем character profile.

## 7. Вход во влагалище и влагалище

- touch + vaginal_opening: коснуться входа;
- stroke + vaginal_opening: провести пальцем у входа;
- press + vaginal_opening: надавить у входа;
- insert + vagina: ввести палец/пальцы;
- remove + vagina: вывести/убрать палец или предмет;
- move_inside + vagina: двигать пальцем/пальцами внутри;
- flex_inside + vagina: сгибать палец внутри — физический факт, если он реально нужен сцене.

LANGUAGE:
- «ввести палец» — NEUT;
- «просунуть палец внутрь» — COLL;
- «вставить палец» — COLL/direct;
- «засунуть палец» — VULG/direct.

## 8. Анальная область

- touch + anus: коснуться ануса / задней дырочки;
- stroke + perianal: погладить вокруг;
- circle + anus: провести пальцем вокруг;
- press + anus: надавить;
- insert + anus: ввести палец/предмет;

## 9. Мастурбационные действия

«Мастурбировать» — PRACTICE/общее название процесса. Физические ACTION внутри могут быть разными.

Современные формы общего процесса:
- мастурбировать — NEUT;
- заниматься мастурбацией — NEUT/formal;
- ласкать себя — COLL/soft;
- трогать себя — COLL/contextual;
- доставлять себе удовольствие — EUPH/NEUT;
- удовлетворять себя — NEUT/formal;
- играть с собой — COLL/JOKE/EROT;
- доводить себя до оргазма — NEUT/COLL;
- дрочить — VULG/COLL;
- дрочить себе — VULG/COLL.

Конкретная сцена по возможности описывается через физические ACTION, а не только общим ярлыком.

## 10. Ограничение движений

ACTION:
- action.hold — удерживать;
- action.pin — прижимать/фиксировать телом;
- action.restrain — ограничивать движение;
- action.bind — связать / привязать;
- action.cuff — пристегнуть наручниками/манжетами;
- action.fix_wrists — зафиксировать запястья;
- action.fix_ankles — зафиксировать щиколотки;
- action.position — удерживать/задавать позу;
- action.legs_open — удерживать ноги разведенными.

Связывание само по себе не определяет CONSENT или PRACTICE.

## 11. Болевое и ударное воздействие

ACTION:
- pinch — щипать;
- bite — кусать/прикусывать;
- scratch — царапать;
- slap — шлепать/хлопать;
- strike — ударять;
- squeeze — сильно сжимать;
- pull — тянуть;
- twist — выкручивать/крутить;
- hair_pull — тянуть за волосы.

PAIN, PLEASURE, INJURY и CONSENT фиксируются отдельно.

Для потенциально травматичных вариантов справочник хранит семантическое название, но не описывает технику безопасного/опасного выполнения.

## 12. Демонстрация и наблюдение

ACTION:
- notice — заметить;
- glance — взглянуть;
- look — посмотреть;
- look_longer — задержать взгляд;
- watch — наблюдать;
- stare — пялиться / пристально смотреть;
- secretly_watch — тайно наблюдать;
- peek — подсматривать / подглядывать;
- show — показать часть тела;
- uncover — открыть/обнажить;
- undress — раздеться;
- pose — позировать;
- expose_intentionally — намеренно оголиться;
- record — снимать фото/видео;
- photograph — фотографировать.

LOOK не равно PEEK: подглядывание включает скрытность.

## 13. Одежда и доступ к телу

- remove_clothing — снять одежду;
- lift_clothing — поднять/задрать предмет одежды;
- lower_clothing — спустить/опустить;
- pull_aside — отодвинуть/сдвинуть;
- open_clothing — расстегнуть/открыть;
- cover — прикрыть;
- uncover — открыть;
- adjust — поправить.

Движение одежды должно иметь естественную физическую причину по Writing Pipeline.

## 14. Игрушки и предметы

Универсальные ACTION:
- insert;
- remove;
- wear;
- attach;
- press;
- vibrate;
- activate;
- deactivate;
- control;
- adjust.

Конкретный предмет задается CONTACT_OBJECT/PRACTICE. Не создавать отдельный глагол для каждой игрушки, если физическое действие уже описывается существующим ACTION.

## 15. Параметры записи действия

Минимум:
- ID;
- ACTOR;
- TARGET_PERSON;
- BODY_TARGET;
- INTENSITY;
- INTENT;
- CONSENT.

По необходимости:
- CONTACT_OBJECT;
- DURATION;
- RHYTHM;
- RISK;
- PRIVACY;
- AWARENESS;
- PRACTICE;
- POSSIBLE_RESPONSE;
- POSSIBLE_OUTCOME.

POSSIBLE не означает автоматическое следствие.
