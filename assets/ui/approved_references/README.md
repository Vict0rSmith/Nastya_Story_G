# Approved UI visual references

Эта папка содержит **approved visual references** для крупных экранов интерфейса Nastya Story.

Файлы:

- [`phone.png`](phone.png) — визуальный референс телефона;
- [`nastya-card.png`](nastya-card.png) — визуальный референс карточки Насти;
- [`wardrobe.png`](wardrobe.png) — визуальный референс гардероба;
- [`inventory.png`](inventory.png) — визуальный референс инвентаря.

## Статус и область действия

Эти изображения утверждены как визуальные референсы для:

- общей композиции экранов;
- предметной оболочки;
- визуальной иерархии;
- характера панелей, карточек и сеток;
- общего направления оформления.

Они **не являются**:

- источником игровых фактов, биографии, расписаний, баланса или механик;
- pixel-perfect макетами, которые требуется копировать координата-в-координату;
- источником точных цветов, размеров, шрифтов, радиусов и состояний компонентов, если соответствующее правило уже задано в `docs/systems/UI_VISUAL_SYSTEM_SPEC.md`;
- основанием сохранять устаревшие подписи или данные, видимые на старом макете.

При конфликте между изображением и `docs/systems/UI_VISUAL_SYSTEM_SPEC.md` приоритет имеет дизайн-система. При конфликте текста на изображении с каноническими системными/world-файлами приоритет имеют соответствующие канонические источники.
